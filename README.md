# CSA08 Assignment 4 – File Handling, Modules and Packages

## Contents
- Task01: repaired mess-bill file processor and sample input.
- Task02: monthly biometric attendance processor and sample daily files.
- Task03: custom exception and attendance parser.
- Task04: defective demonstration and repaired append-based log processor.
- Task05: four code organisations: one script, one module, three modules, and a package.
- Task06: college fest registration package with sample department files.

## Requirements
Python 3.8 or later. All programs use the Python standard library; no external packages are required.

## Run commands
Run each command from its task folder:
- Task01: `python Task01_Repair_Mess_Bills.py mess_oct.txt`
- Task02: `python Task02_Attendance_Processor.py`
- Task03: `python Task03_Exception_Handling.py`
- Task04: `python Task04_File_Forensics.py`
- Task05(a): `python attendance_all_in_one.py`
- Task05(b): `python main.py` from `b_one_module`
- Task05(c): `python main.py` from `c_three_modules`
- Task05(d): `python main.py` from `d_package`
- Task06: `python main.py` from `Task06`

## Results
Each program prints or creates the reports described in its task. Timing and output evidence should be captured after running the programs on the submission computer.
